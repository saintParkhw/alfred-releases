궁금한 점

베팅을 대신 해 주나요?

아니요. 알프레드는 분석만 합니다. 구매는 베트맨 공식 사이트에서 직접 하고, '베트맨 열기'는 고른 목록을 복사해 구매 화면을 열어 주는 기능입니다.

돈을 벌 수 있나요?

보장하지 않습니다. 베트맨 환급률이 0.85~0.87이라 어떤 방식이든 장기적으로 손해가 나기 쉽습니다. 알프레드는 확률을 정확하게 보여 주고, 덜 손해 보는 선택을 고르기 쉽게 만드는 도구입니다.

실행하면 Windows 경고가 떠요.

새로 배포된 프로그램이라 SmartScreen이 '알 수 없는 게시자'로 표시할 수 있습니다. [추가 정보]를 누른 뒤 [실행]을 누르면 됩니다.

다른 PC에서도 쓸 수 있나요?

네. 같은 계정으로 로그인하면 산 분석과 한달권이 그대로 따라갑니다.

결제하면 언제 열리나요?

송금 메모의 주문번호로 확인한 뒤 바로 열립니다. 프로그램을 켜 두면 따로 누를 것 없이 자동으로 바뀝니다.

업데이트는 어떻게 하나요?

프로그램을 켤 때 새 버전이 있으면 자동으로 업데이트합니다.

Mac이나 휴대폰에서도 되나요?

지금은 Windows 10/11 PC 전용입니다.
